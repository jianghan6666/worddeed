# Relevance screening

All screening material is collected here. The completed application uses twelve P0 trials, with three readers per trial and two reading stages. Primary first saves and supplementary recoveries remain separate.

| Folder | Purpose | Start here |
| --- | --- | --- |
| `review/` | Read the completed pilot: memo, catalogue, prompts, analysis tables and all 24 handoffs. | [Memo](review/MEMO.md), [trial index](review/TRIAL_INDEX.csv) |
| `experiment/` | Inspect the ratified protocol, collection records, canonical saved analyses and frozen replay code. | [Plan](experiment/PLAN.md), [saved-result package](experiment/results-2026-10-21/README.md) |
| `history/` | Earlier comparison material, retained as historical context. | [19 October comparison](history/comparison-2026-10-19/) |

For convenient topic-by-topic reading, open the [results browser](../../results/step2/explorers/index.html) locally. For offline recalculation and restoration of literal reader evidence, follow [REPLICATION.md](../../REPLICATION.md). The replay requires no new AI judgments.

The review copies and canonical experiment retain their original scientific bytes and provenance. Repository-relative paths inside historical indexes are resolved by [replication/paths.json](../../replication/paths.json). Verify the reading copy from the repository root with `python study/screening/review/verify.py`.
