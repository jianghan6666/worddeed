01 / Research questionPrediction and measurement

What does the prediction measure?

Language expresses a perspective. Behavior records a choice. Both also reflect circumstances.

We study their relationship while keeping the measurement claim open. A model trained to predict R&D/assets may capture risk preference, industry, opportunity, disclosure practices, or a mixture of these. Predictive performance alone cannot resolve that interpretation.

Narrative inputs

Managerial speech

Selected topic features and aggregate sentiment summarize the supplied speech data.

Behavioral target

R&D / assets

Observed investment supplies the supervised learning target; it is not an independent validity criterion for the resulting score.

Model output

Predicted behavior

A generated proxy whose psychological meaning needs evidence beyond the training relationship.

02 / Four-step methodCurrent implementation

The method that is connected.

The adapters reuse the delivered scientific code and preserve its settings. Empirical programs and inputs are configured externally. Saved inputs, selected topic IDs, score files and model inputs form the handoffs.

  1. 01

    Topic representation

    Input
    Saved catalogue, topic densities and component metadata.
    Procedure
    Bind the ordered 354-topic catalogue and delivered density matrix. Optional inference reuses the existing topic-model implementation and checks model identity.
    Output
    Topic densities and catalogue for the fixed study.

    Saved row ordering is delivery-declared. The assembly does not independently authenticate historical unkeyed ordering or create new-corpus sentiment.

    Step 1 adapter ↗
  2. 02

    Relevance screening

    Input
    All 354 descriptors, followed by the frozen source passages.
    Procedure
    Three independent initial readings; seal all initial responses; continue each reader’s own history through Stage B; export a two-of-three relevance majority.
    Output
    Selected topic IDs, initial labels, reasons and minority votes.

    Confidence does not weight votes. The delivered primary is Astra xhigh, repetition 1: 321 selected topics.

    Screening adapter ↗
  3. 03

    Behavioral prediction

    Input
    Selected topic features, aggregate sentiment and R&D/assets.
    Procedure
    Reuse the supplied Ridge and XGBoost training scripts, firm–CEO connected-component grouping, five folds, seeds and tuning grids.
    Output
    New scores, including grouped out-of-fold predictions.

    The predictors are topic features plus aggregate sentiment. This is not the earlier scalar-N-plus-controls specification.

    Step 3 adapter ↗
  4. 04

    Matching & estimation

    Input
    The new score file and original financial/CEO identity sources.
    Procedure
    Pass scores to the original matcher, check keys and folds, prepare the same 25 formulas, then estimate separately in Stata.
    Output
    Matched data, model inputs, estimation receipts and tables when executed.

    Regression score = 100 × max(out-of-fold predicted R&D/assets, 0). Preparation and estimation have separate completion states.

    Step 4 adapter ↗

03 / Agent architectureBounded execution

Four tools.
One durable workflow.

The coordinator selects permitted operations. The dispatcher enforces order, and saved artifacts determine completion. Direct and agent execution use the same workflow.

Research authority

Researchers determine constructs, scientific specifications and interpretation. The coordinator cannot change the method or execute arbitrary commands.

Reader recovery. Initial responses and reader histories persist. Resume skips completed pages. Invalid or uncertain attempts remain visible and require explicit recovery; labels are not silently repaired.

06 / Evidence and limitsSeparate claims

Connections are inspectable.
Validity remains empirical.

The received results, the assembly checks, and the measurement claims have different evidential status. Completion of one does not imply completion of the others.

01

Received scientific work

The fixed catalogue, completed screening trials, and supplied Step 3–4 packages are existing research artifacts. The delivered primary selection has 321 topics. This package includes aggregate results; complete study inputs are supplied separately.

02

Assembled software

Four adapters, a coordinator and saved state connect those interfaces. The package includes self-contained tests for the coordinator, handoffs, and resume, plus optional adapter checks. Fixtures cover handoffs, reader independence, completion and recovery.

03

Empirical execution

A coherent real run is a separate action requiring the complete assets and compatible runtimes. Stata estimation follows model preparation. The narrated fixture does not execute these stages scientifically.

04

Construct interpretation

Prediction and conditional associations do not establish psychological validity, causality, or superiority over other measures. Missing R&D handling, industry content, contemporaneous timing, and historical data alignment require substantive attention.
