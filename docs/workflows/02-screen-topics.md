# Screen for construct relevance

## Inputs

Construct definition, complete topic catalogue, source packets, reader settings, and compatible screening toolkit.

## Procedure

Run three independent initial readings of the complete catalogue. Seal all three before releasing source passages. Each reader reviews the complete source task in its own history without peer votes. Preserve literal responses, reasons, failures, and missingness. Export a two-of-three majority; confidence does not weight votes. Any recovery is explicit and recorded.

## Output

Selected and excluded topic IDs, unresolved cases, all judgments and reasons, and minority votes.

Use the [runtime guide](../../agent_system/empirical/README.md) for commands. The [completed example](../../examples/ceo-risk-preference/README.md) illustrates the delivered method; the [roadmap](../ROADMAP.md) identifies further assessment.
