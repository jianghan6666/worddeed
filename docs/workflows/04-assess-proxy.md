# Assess the proxy

## Inputs

Score file, observation/identity records, and downstream analysis specifications. The CEO application uses financial records and dividend outcomes; other applications define their own assessment data and outcomes.

## Procedure

Check matching and observation keys, then prepare the specified models. Estimation is a separate resumable step. Inspect sample changes, failures, coefficients, and uncertainty. Explain competing interpretations and evidence needed for construct claims.

## Output

Matched model inputs, estimation records, tables, diagnostics, and researcher interpretation.

Use the [runtime guide](../../agent_system/empirical/README.md) for commands. The [completed example](../../applications/ceo-risk-preference/README.md) illustrates the delivered method; the [roadmap](../ROADMAP.md) identifies further assessment.
