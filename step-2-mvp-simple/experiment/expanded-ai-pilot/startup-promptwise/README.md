# Closed direct-reader execution package

The [ratified study](../PLAN.md) is the completed **12-trial P0 cohort**, with 36 independent readers, 72 stage records and 648 review-page dispositions. Scope amendment 3 was ratified after collection on 21 October 2026. The other 72 originally scheduled trials were never started and are superseded historical work.

**No new seats or trial admissions are authorized.** There is no CMD layer. The current coordinator completed direct dispatch, continuation, sealing and final analysis. [EXECUTION_SCHEDULE.json](EXECUTION_SCHEDULE.json) lists exactly the 12 completed assignments; [DIRECT_DISPATCH.md](DIRECT_DISPATCH.md) records the closed workflow.

The unchanged [Stage A wrapper](READER_STAGE_A_WRAPPER.md), [Stage B wrapper](READER_STAGE_B_WRAPPER.md) and [transport policy](TRANSPORT_POLICY.md) preserve the instructions used during collection. Each reader kept the same native chat across both stages. All three initial dispositions preceded that trial's review release, and all review dispositions preceded final voting. These files are provenance and do not reopen collection.

[Bindings](BINDINGS.json) distinguish frozen revision-9 scientific inputs from the current administrative scope. The [original schedule](../historical/revision-9-SCHEDULE.json) and [prior direct-dispatch package](../historical/amendment-2/startup-promptwise/README.md) are preserved. See [results, limitations and measured usage](../results-2026-10-21/README.md) before proposing any extension.
