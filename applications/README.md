# Applications

AI Microfoundation Proxy provides a shared workflow for constructing and assessing behavioral proxies from narrative evidence. Each application defines its own construct, narratives, behavioral target, observation unit, scientific methods and assessment criteria.

| Application | Question and inputs | Status |
| --- | --- | --- |
| [CEO risk preference](ceo-risk-preference/README.md) | Earnings-call speech predicts R&D/assets; downstream analysis examines dividend decisions. | Completed results and verified reproduction; construct validation remains open. |

Each application keeps its walkthrough, scientific material, results and replication evidence together. The CEO application is the first worked case. Its target, model choices, sample and financial-data requirements are application-specific.

To develop another case, follow [Adding an application](../docs/NEW_APPLICATION.md) and start from the [application template](_template/README.md). The template is a research and implementation plan, not a runnable second application. The current numerical adapters and empirical reproduction drivers target the CEO study; another case requires explicit scientific configuration and, where needed, new adapters.
