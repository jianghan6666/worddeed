# 完整包与精简包的区别

| 内容 | 之前的精简 Step 4 包 | 本次完整包 |
|---|---|---|
| 回归范围 | 第3、4页的16个score模型 | 完整Excel，9个Replication模型及16个score模型 |
| 财务、薪酬、期权、证券及利率 | 已处理输入 | 原始下载、SQL、查询及字段说明，从原始记录重建 |
| 年度CEO与基础资格 | 说明与既有标记 | 重新选择唯一财年末CEO，执行行业、证券和完整性筛选 |
| 市场与期权变量 | 既有计算值 | 从原始日/月度及逐笔期权重新计算 |
| 公司、CEO和时间匹配 | 既有结果与说明 | 官方原始连接表、未聚合身份明细和重新匹配程序 |
| Ridge/XGBoost分数 | 冻结OOF分数 | 同一批冻结OOF分数，不重新训练 |
| 展示 | 两页Excel及16模型结果 | 原完整Excel；运行后生成7个自有结果面板 |

本次运行从原始财务、证券、薪酬和身份连接输入开始。原讲话数据投影保留全部1,775,355行和14个被匹配代码读取的字段，保持原值、原类型及顺序；其中1,420,208行被源面板component map实际使用。全局人员冲突守卫在全部身份行上计算，没有提前仅保留最终样本。讲话正文不参与此阶段，不随包复制。来源文件SHA、字段清单、逐值核验及可选导出脚本均保留。

已有分数及其源panel_id、讲话者和公司自然年定义按用户要求冻结。本包不重做讲话收集、主题和情绪提取、ML训练，也不按新官方链接重训或把已有分数搬到另一个GVKEY。官方核验只决定是否接纳当前候选配对。

年度B和无Delta/Vega是当前冻结口径。原财务模块为保持分析逻辑不变，内部仍导出历史A诊断表；当前25模型只用B，不估计A或PCEO。原论文发表数值属于Excel中的文献参考，不是重新估计的第26个模型。

原作者样本及全部未披露操作没有恢复。本包复现当前项目的Excel和研究口径，不把数据链条重建成功称为精确恢复作者样本。

reference数据只用于重建后的断言和对照。财务构建不读取参考计算值；匹配不用最终参考标记代替桥表核验；模型阶段先从新数据计算样本、设计和数值尺度，再与声明比较。不一致会停止，不会强制改到参考样本。
