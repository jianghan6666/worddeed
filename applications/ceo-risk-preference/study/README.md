# Study materials

The CEO speech, R&D and dividend-policy application is organized by its four scientific stages. Read [the full results](../RESULTS.md) for findings and [the replication guide](../REPLICATION.md) for execution.

| Stage | Folder | Contents |
| --- | --- | --- |
| 1. Represent narrative | [representation/](representation) | Original CEO/R&D implementation, topic-model specifications, methods and notebooks. |
| 2. Screen relevance | [screening/](screening/README.md) | One home for the twelve-trial review, experimental protocol, saved analyses and screening history. |
| 3. Predict behavior | [prediction/](prediction/README.md) | Supplied prediction package: panel construction, Ridge/XGBoost code, method and saved metrics. |
| 4. Assess the proxy | [assessment/](assessment/README.md) | Full raw-data analysis and the separate compact score-model route. |

These are the original scientific sources and reading copies. The presentation of their outputs lives in [applications/ceo-risk-preference/results/](../results/README.md); download, restore and reproduction tools live in [replication/](../../../replication/README.md). Large data and model files are restored from the frozen private input release using the replication guide.

The original package contents and archive-member names remain bound to their historical hashes. Historical documents may use the former repository paths or paths within the complete restored package. [The repository guide](../../../docs/REPOSITORY.md) explains the current locations and the historical path map. Use the current replication guide for executable commands.
